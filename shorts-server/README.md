# Шортсы на автопилоте (Timeweb + Claude Code)

Сервер каждые 15 минут проверяет папку `inbox/`. Если там есть видео или файл `links.txt`
со ссылками, Claude Code расшифровывает речь (whisper), выбирает лучшие моменты,
режет вертикальные ролики 1080×1920 с субтитрами и кладёт их в `outbox/`.
Если настроен Telegram, готовые ролики приходят туда. Компьютер для этого не нужен.

## 1. Создать сервер в Timeweb Cloud

- **Локация: Нидерланды или Германия.** Из России Claude недоступен, и сервер в РФ работать не будет.
- ОС: Ubuntu 24.04. Минимум 4 vCPU, 8 ГБ RAM, диск 80 ГБ.
- В поле **Cloud-init** (скрипт при создании) вставить **целиком** содержимое `install.sh`.
  Если такого поля нет, после создания сервера выполнить в консоли под root: `bash install.sh`.

Установка идёт 5–10 минут после запуска сервера.

## 2. Дать Claude доступ (один раз)

Подключиться к серверу (`ssh root@IP` или «Консоль» в панели Timeweb) и выполнить:

```bash
su - shorts -c '~/.local/bin/claude setup-token'   # откроет ссылку, войти в аккаунт Claude
nano /home/shorts/shorts/.env                      # вставить токен в CLAUDE_CODE_OAUTH_TOKEN=
```

Для Telegram (необязательно): создать бота у @BotFather, в `.env` заполнить `TG_BOT_TOKEN`
и `TG_CHAT_ID` (свой id можно узнать у @userinfobot) и один раз написать боту `/start`.

## 3. Пользоваться

- **Ссылки:** добавить их по одной на строку в `/home/shorts/shorts/inbox/links.txt`.
- **Файлы:** `scp video.mp4 root@IP:/home/shorts/shorts/inbox/`,
  затем `chown shorts: /home/shorts/shorts/inbox/*`.
- **Результат:** `outbox/<видео>/` с роликами и `README.md` (заголовки, описания, хэштеги).
- **Логи:** `logs/`.
- **Запустить сразу, не дожидаясь cron:** `su - shorts -c ~/shorts/run.sh`.

YouTube часто блокирует серверные IP-адреса. Если ссылки не скачиваются, загружайте файлы напрямую.

## Настройки (`.env`)

| Переменная | Что делает |
|---|---|
| `SHORTS_PER_VIDEO` | сколько шортсов делать из одного видео (по умолчанию 5) |
| `WHISPER_MODEL` | качество расшифровки: `small` работает быстро, `medium` точнее, но медленнее |

Правила отбора моментов лежат в `TASK.md`. Это обычный текст, его можно менять.
