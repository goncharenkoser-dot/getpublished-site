## Редизайн главной (сделано в ветке `redesign`, ждёт решения)

Ветка живёт в отдельном worktree `~/Projects/website-redesign`
(`node_modules` там символическая ссылка на основной). Старая версия
остаётся на `main`. Серверы после перезапуска сессии:

    cd ~/Projects/website && npm start                       # 8080, старая
    cd ~/Projects/website-redesign && npx eleventy --serve --port=8081   # 8081, новая

Навыки поставлены в `.claude/skills/` (taste-skill, redesign-skill,
impeccable). Хук impeccable и его бинарник намеренно не включены: лаунчер
скачивает и запускает движок на каждом редактировании; включить можно по
решению заказчика (`.claude/skills/impeccable/scripts/impeccable`).

### Design read
Redesign-preserve посадочной школы (режим Persuade) для русскоязычных
будущих авторов нон-фикшна, большинство с телефона. Фирменный язык
сохраняется: Unbounded + Manrope, крем/оранжевый/тёмно-коричневый.
Дiалы: VARIANCE 6, MOTION 5, DENSITY 4. Контент не трогаем.

### Аудит текущей главной
- Две системы компонентов: `.btn` (чёрная, строчные, 8px) и `.bp-btn`
  (капслок, жёлтый на чёрном, 12px); две подписи `.label`/`.bp-label`;
  радиусы 14/12; контейнеры 1200/1240/1400; ритм секций 96px и clamp.
- Кикеры (uppercase-подписи над заголовками) почти в каждой секции;
  impeccable их запрещает, taste-skill допускает ≤1 на 3 секции.
- Тёмные вставки разбросаны: этапы, разбор, команда, отзывы, подвал;
  оранжевые: «Автор ПРО» и «О школе». Читается как пять разных сайтов.
- Одинаковые сетки карточек 4×1 в семи секциях подряд (персоны, кейсы,
  этапы, статьи, команда, отзывы, курсы).
- Три бегущие строки на мобильном (герой ×2, обложки) + пульсы кнопок.
- Герой: верхний отступ 118px при лимите ~96px; заголовки то по центру,
  то слева.

### План
1. Единые токены: одна кнопка (фирменная bp: чёрная + жёлтый капслок,
   12px; вторичная контурная), один стиль подписи без кикеров, радиусы
   кнопки 12 / карточка 16 / тег pill, контейнер 1200 (шапка 1400),
   ритм секций clamp(64px, 9vw, 120px), заголовки слева.
2. Сценарий поверхностей: светло до курсов → оранжевый «Автор ПРО» →
   тёмный «персональный разбор» → снова светло до конца → тёмный подвал.
   Этапы, команда, отзывы, «О школе» становятся светлыми.
3. Семейства раскладок без повторов: персоны без коробок (диск + текст),
   на мобильном горизонтальный snap-ряд; кейсы списком с линиями; этапы
   как картинка + вертикальный список; команда как фото-плитки с подписью;
   статьи как газетный индекс без карточек; отзывы в две колонки без рамок.
4. Движение: орбита героя остаётся единственным авторским моментом;
   обложки из бегущей строки в snap-полосу; пульсы кнопок и мигающую
   точку убрать; hover/active/focus у всех контролов.
5. Мобильный: 44px цели, кнопки на всю ширину, шрифт ≥16px, проверка
   каждой секции на 390px; hero top padding ≤ 64px.
6. Выложить: новая версия на 8081; при желании опубликовать главную
   артефактом с инлайном ассетов.

### Статус
Пункты 1–5 плана выполнены и проверены на 1280/1440 и 390px (коммиты
4616d69, ea06e78). Первый экран с орбитами и копирайтинг не тронуты.
Сравнение: старая версия на 8080 (`main`), новая на 8081 (`redesign`).
Чтобы принять редизайн: `git checkout main && git merge redesign`.

виджет GetCourse во всплывающем окне; в опубликованном артефакте главной
этот виджет и внутренние ссылки меню не работают, это только превью дизайна.
